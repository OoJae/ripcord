Under canopy

The loop that pulled

  1. Sense

    Reads the chain directly. Prices are cross-checked against an independent Chainlink feed — a corrupted oracle blocks the defense instead of sizing it.

  2. Plan

    One model proposes one action with one amount. It cannot name an address; addresses only exist in config.

  3. Critique

    A second, independent model must approve. No approval, no transaction — ever.

  4. Guard

    Fourteen deterministic rules re-derive every figure. Final authority; it trusts neither model.

  5. Execute

    Lands through KeeperHub: retries, smart gas, sponsorship, and the workflow re-reads the chain before it will write.
